# mo-chemistry

Химиками были предоставлены конфиденциальные данные о 1000 химических соединений с указанием их эффективности против вируса гриппа. Параметры, характеризующие эффективность, обозначаются как IC50, CC50 и SI

# Постановка задачи

Подобрать наиболее эффективное сочетание параметров для создания лекарственных препаратов.

# 📂 Структура проекта
```
├── README.md                     # Описание репозитория
├── Analytical_report.pdf         # Аналитический отчет
├── analysis.ipynb                # Ноутбук с анализом данных

├── regression_IC50.ipynb         # Ноутбук с регрессия для IC50
├── regression_SI.ipynb           # Ноутбук с регрессия для SI
├── classification_СС50.ipynb     # Ноутбук с классификацией: превышает ли значение CC50 медианное значение выборки
├── classification_IC50.ipynb     # Ноутбук с классификацией: превышает ли значение IC50 медианное значение выборки
├── classification_SI.ipynb       # Ноутбук с классификацией: превышает ли значение SI медианное значение выборки

│   ├── raw.xlsx                  # Оригинальный и обогащенный датасет
```
